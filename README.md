# Gastos SCOTT-ISB 2027

Landing móvil interna para subir facturas y tickets del equipo. Sin dependencias (HTML + CSS + JS).

- `index.html`, `styles.css`, `app.js`: la aplicación.
- `config.js`: dirección del servidor (Google Apps Script). No contiene contraseñas ni datos personales.
- La clave de acceso, las personas, los eventos y los conceptos los entrega el servidor tras validar la clave.

Prueba local sin servidor: abrir `index.html?mock=1` y usar la clave `demo`.
